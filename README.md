# 🏗️ Projects

## 🏋️ [FitNow](https://github.com/HariBalaji24/fitnow1) — AI Powered Fitness & Wellness Platform
**PERN Stack • Gemini AI • PostgreSQL • OAuth**

FitNow is a full-stack AI-driven fitness and wellness platform focused on personalized health tracking, workout generation, nutrition planning, and wellness assistance.

### 🚀 Features

- Implemented secure OAuth authentication and protected user sessions.
- Designed an interactive fitness dashboard for tracking workouts, progress, and wellness-related activities.
- Collected personalized onboarding data including user goals, fitness preferences, and lifestyle information to generate tailored AI-driven responses.
- Integrated Gemini AI to generate customized workout routines based on user fitness goals and preferences.
- Built an AI-powered health & skincare assistant chatbot capable of handling wellness and skincare-related queries.
- Developed AI-generated diet planning functionality using user-specific health and nutrition data.
- Structured scalable REST APIs and relational database models using PostgreSQL.
- Managed complex frontend state efficiently using Redux Toolkit for predictable UI behavior and optimized rendering.

## 📺 [AniStack](https://github.com/HariBalaji24/Anistack) — Anime & Manga Tracking Platform
**MERN Stack • Jikan API • JWT Authentication**

AniStack is a full-stack anime and manga tracking platform built to help users organize and manage their watching and reading progress efficiently.

### 🚀 Features

- Integrated the Jikan API to fetch detailed anime and manga information including ratings, genres, popularity, episode counts, and release details.
- Developed personalized tracking systems for anime watch progress and manga reading progress.
- Displayed remaining episodes, chapters, and estimated watch/read duration dynamically.
- Implemented anime tracking categories including Watching, Completed, On Hold, and Planned.
- Built interactive episode and chapter progress systems where users can mark content as watched or read dynamically.
- Displayed detailed statistics and metadata for anime and manga collections.
- Engineered secure JWT-based authentication and persistent user session management.
- Optimized asynchronous API handling and frontend rendering for smoother user experience.
